# 《他拔剑，不是为了杀她》— Kling 4K Source Plate 生成清单

## 生成策略

当前账号的 `kling-video-v3_0` 已确认支持 `3–15s` 和 `4k`。本项目不把所有片段机械地设成 4 秒，而是按动作复杂度取最短可用时长：

- 微动作、凝视、静态觉醒：`3s`
- 有明确动作峰值或两个连续动作：`4s`
- 不使用 5s；当前没有需要更长连续表演的镜头
- `S10` 复用 `S09` 的 D03 源片，不新增 Kling 任务

这样 9 条唯一 source plate 共生成 `32s`，原先统一 4s 是 `36s`；实际灵感值仍以可灵返回为准，不能简单按秒数直接换算价格。

## Kling 参数锁定

| 参数 | 值 |
|---|---|
| tool | `image_to_video` |
| model | `kling-video-v3_0` |
| resolution | `4k` |
| aspect ratio | 跟随 9:16 首帧，不额外传入 |
| imageCount | `1` |
| prefer_multi_shots | `false`，保持单镜头连续动作 |
| enable_audio | `false`，最终音频由项目 BGM 混音 |
| first_image | 对应 FF 首帧，先由 CLI 上传 |

提示词只描述“从首帧开始发生的运动”，不重复要求 Kling 改变构图；4K、9:16、时长使用参数传入，不写成提示词里的模糊要求。

## 公共身份与质量约束

以下要求已融入每条提示词：保持首帧人物身份、构图、服装和主要道具；单一连续镜头；动作从首帧状态开始；不自动切换景别；不新增人物；不生成字幕、水印或 logo；不让静态效果突然变成混乱爆炸。

### S01 / D01 剑锋抵喉 — 3s

首帧 FF01 是绝对构图基准。固定低机位双人镜头，保持男主在左前景、女主双膝跪在较低位置、剑锋横在喉前但不接触皮肤。前半段几乎静止，只让雨丝、衣摆和远处悬剑产生极轻微运动；随后女主眼神从男主剑锋缓慢移到男主脸部，男主手腕施加极小的压迫感但不挥剑、不刺入。女主始终保持跪姿和冷静表情，男主始终没有杀意爆发。万剑只做低频悬浮，天门和背景不变。单镜头连续、构图稳定、无推拉摇移、无镜头旋转、无切镜。禁止女主站起、半蹲或倒下，禁止剑锋穿喉、血迹、爆光、额外人物、额外武器、断剑、文字、字幕、水印、logo、运动模糊和大范围粒子。

### S02 / M01 男主抬剑 — 3s

首帧 FF02 是绝对构图基准。寒渊剑修男主保持银白半束长发、冰蓝发带、冰蓝眼睛和银白浅灰蓝长袍，在原地完成一次平稳而有压迫感的抬剑动作：从当前预备位置抬高肩肘和手腕，剑身上移到审判姿态，动作结束后短暂停住。男主脸部保持冷静严厉，背景万剑只让少量符文逐渐亮起，不发生全面坠落。保持首帧已有剑的视觉关系，不新增、复制、分裂或重组男主手中的剑，也不要让背景万剑与男主剑合并；不挥砍、不劈落、不产生冲击波。固定低角度单镜头，无镜头旋转、无切镜、无运动模糊。禁止额外人物、额外手臂、畸形手、断剑被进一步放大、双剑、悬浮剑身、爆炸、文字、字幕、水印、logo。

首帧 FF03 是绝对构图基准。保持女主脸部近景、黑发、黑红衣领、暗金眉心封印和下方横向冰蓝剑锋的位置不变。女主先保持平静，再用一次很小的眼神动作从画外男主方向抬眼并锁定，睫毛轻微颤动，头部不要转动，嘴唇不要说话。剑锋始终停在脸部下方且不接触皮肤，锁链只在虚化背景中轻微震动。眼神表达“她早已知道他的选择”，不要出现恐惧或夸张惊讶。固定近景单镜头，无推拉、无切镜、无头发飞散、无觉醒爆光、无封印裂开、无红色能量爆发。禁止额外人物、变脸、五官漂移、文字、字幕、水印、logo、运动模糊和粒子遮脸。

## 提交前检查

每条任务提交前都要再次确认：`first_image` 与表格一致、时长与表格一致、`prefer_multi_shots=false`、`enable_audio=false`、`imageCount=1`。提交后先记录真实 `generationId`、`creditsConsumed` 和 `providerTaskId`，下载后再做 ffprobe、接触表和人工 QC；没有用户批准，不得把生成结果写成 `approved`。
